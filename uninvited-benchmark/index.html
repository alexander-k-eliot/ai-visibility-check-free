What this actually shows

These are real, established local businesses — an insurance broker, a security company, a senior-care franchise, a fire-protection contractor, a newspaper's ad arm. None of them asked to be checked. That's the point: AI-visibility gaps aren't a "startup problem" or a "big company problem," they're just the default state of the web right now, chamber-of-commerce members included. 1 real llms.txt out of 9 scorable sites (11%) is roughly in line with every other vertical we've benchmarked this year, not an outlier.

Methodology

Every result above comes from a real, direct server-side fetch of the business's own homepage and root-level `llms.txt`/`robots.txt`, dated 2026-07-26, using a clearly-identifying User-Agent. llms.txt was only counted as real if it returned a genuine `text/plain` response, not an HTML soft-404 (an earlier pass on this exact data caught 3 false positives this way, corrected before publishing — worth stating plainly rather than hiding). AI-crawler blocking checked against the same 8 user-agents used across every benchmark on this site. This is a lighter, 4-point spot-check, not the full 9-point weighted score used on the main benchmark pages — stated honestly, not implied to be more than it is.
